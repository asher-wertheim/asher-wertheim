# Hi, I'm Asher

Ops lead turning into a product builder. I build small apps for real problems I had at home or at work.

I plan each one like a PM, with the problem, a spec and a clear scope first. Then I build it with AI coding tools like Claude Code, test it and ship it.

## Projects

### [Kupa](https://github.com/asher-wertheim/Kupa) · [Live app](https://kupa-expense-tracker.netlify.app)
A shared budget app for couples. Both partners log expenses in seconds and see one number: how much is left until the next credit card billing cycle. This was my final project in the Hebrew University Product Management course. I took it from discovery and PRD to a live app.

`TypeScript` `React` `Supabase` `PWA` `Vitest` `Playwright`

### [PDFusion](https://github.com/asher-wertheim/PDFusion) · [Live app](https://pdfusion-tools.netlify.app)
Free PDF tools: merge, split, compress, convert, watermark and protect. Every file is processed in your browser, so nothing gets uploaded.

`TypeScript` `Client-side only`

### [DittoMac](https://github.com/asher-wertheim/DittoMac)
A clipboard manager for macOS, based on Ditto for Windows. It saves everything you copy and lets you search and paste it again. Your history never leaves your Mac.

`Swift` `SwiftUI` `AppKit`
